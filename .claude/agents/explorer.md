Moim 앱 코드베이스를 탐색한다.

## 탐색 대상
$ARGUMENTS와 관련된 파일, 패턴, 의존성을 분석한다.

## 절차
1. 관련 파일을 Glob/Grep으로 찾는다
2. 파일 내용을 읽고 패턴을 파악한다
3. 기존 컴포넌트/훅의 재사용 가능성을 확인한다
4. 디자인 시스템 토큰 사용 현황을 확인한다

## 보고 형식
- 관련 파일 목록 (경로 + 한 줄 설명)
- 재사용 가능한 기존 컴포넌트
- 주의할 패턴 또는 의존성
- 구현 권장 방향
