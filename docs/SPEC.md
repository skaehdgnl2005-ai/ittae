# 모임 앱 MVP 기능 명세서

## 1. 프로덕트 개요

| 항목 | 내용 |
|------|------|
| 서비스명 | (가칭) 모임 |
| 한 줄 소개 | 친구들과 일정을 맞추고, 장소를 고르고, 추억을 기록하는 올인원 소셜 스케줄링 앱 |
| 타겟 유저 | 정기적으로 친구/동료 모임을 갖는 20~30대 |
| MVP 목표 | 심사위원 시연용 웹앱 (PWA) — 핵심 플로우 완전 동작 |
| 배포 형태 | 웹앱 (모바일 브라우저 최적화) → 추후 네이티브 전환 가능 |

## 2. 핵심 화면별 기능 명세

---

### 2-1. 홈 (통합 캘린더 대시보드)

**목적:** 개인 일정과 모임 일정을 한 화면에서 에디토리얼 스타일로 확인

#### 기능 목록

| ID | 기능 | 설명 | 우선순위 |
|----|------|------|----------|
| H-01 | 월간 캘린더 뷰 | 월 단위 캘린더에 개인/모임 일정을 색상으로 구분하여 표시 | P0 |
| H-02 | 일별 상세 리스트 | 날짜 탭 시 해당 일의 일정 카드 리스트 노출 (시간, 장소, 참여자 썸네일) | P0 |
| H-03 | 개인 일정 등록 | 제목, 날짜, 시간, 메모를 입력하여 개인 일정 추가 | P0 |
| H-04 | 모임 일정 자동 연동 | 확정된 모임 일정이 캘린더에 자동 반영 (모임 색상 배지) | P0 |
| H-05 | 오늘의 요약 카드 | 화면 상단에 "오늘 N개 일정" 요약 + 가장 가까운 일정 하이라이트 | P1 |
| H-06 | 주간 뷰 토글 | 월간 ↔ 주간 뷰 전환 | P2 |

#### 화면 상태

- **일정 없는 날:** 빈 상태 일러스트 + "모임을 만들어보세요" CTA
- **일정 있는 날:** 시간순 정렬된 일정 카드 리스트
- **모임 대기 중:** 투표 미확정 모임은 점선 스타일로 구분 표시

### 2-2. 친구 및 모임 목록

**목적:** 친구를 관리하고, 모임별 실시간 상태를 확인

#### 기능 목록

| ID | 기능 | 설명 | 우선순위 |
|----|------|------|----------|
| F-01 | 친구 목록 | 등록된 친구를 프로필 사진 + 이름으로 리스트 노출 | P0 |
| F-02 | 친구 검색 | 닉네임 또는 고유 ID로 친구 검색 | P0 |
| F-03 | 친구 요청 보내기/수락 | 검색 결과에서 친구 요청 → 상대방 수락 시 등록 | P0 |
| F-04 | 모임 목록 | 내가 참여 중인 모임 리스트 (모임명, 참여 인원, 최근 활동일) | P0 |
| F-05 | 모임 상태 배지 | 각 모임에 실시간 상태 표시: `투표 중` · `확정` · `완료` | P0 |
| F-06 | 빠른 모임 만들기 | 친구 목록에서 멤버를 선택하여 바로 모임 생성으로 이동 | P1 |
| F-07 | 친구 즐겨찾기 | 자주 만나는 친구를 상단 고정 | P2 |

#### 화면 구조

- **상단 탭:** 친구 | 모임 (탭 전환)
- **친구 탭:** 검색바 → 즐겨찾기 섹션 → 전체 친구 리스트
- **모임 탭:** 상태 필터 (전체/투표 중/확정) → 모임 카드 리스트

### 2-3. 모임 상세 (일정 투표)

**목적:** 참여자의 가용 시간을 수집하고 최적 일정을 확정

#### 기능 목록

| ID | 기능 | 설명 | 우선순위 |
|----|------|------|----------|
| V-01 | 모임 생성 | 모임명, 참여자 선택, 후보 날짜(복수) 설정 | P0 |
| V-02 | 시간 투표 | 각 후보 날짜에 대해 참여자가 ⭕ 가능 / △ 애매 / ❌ 불가 투표 | P0 |
| V-03 | 투표 현황 매트릭스 | 날짜 × 참여자 매트릭스로 투표 결과를 시각화 | P0 |
| V-04 | 최적 시간 추천 | 가장 많은 참여자가 가능한 날짜를 자동 하이라이트 | P0 |
| V-05 | 일정 확정 | 방장이 최종 날짜를 선택하여 확정 → 전원에게 알림 | P0 |
| V-06 | 장소 연동 | 일정 확정 후 "장소 정하기" 버튼으로 지도 화면 연결 | P1 |
| V-07 | 참여자 코멘트 | 투표 시 한 줄 코멘트 남기기 ("이 날은 저녁만 돼요") | P1 |
| V-08 | 리마인더 알림 | 투표 미참여자에게 푸시 알림 발송 | P2 |

#### 투표 플로우

```
모임 생성 → 후보 날짜 설정 → 링크 공유/푸시 알림
→ 참여자 투표 → 결과 매트릭스 확인 → 방장 확정 → 캘린더 자동 반영
```

### 2-4. 지도 기반 장소 추천

**목적:** 모임 장소를 지도에서 탐색하고 추천받아 결정

#### 기능 목록

| ID | 기능 | 설명 | 우선순위 |
|----|------|------|----------|
| M-01 | 지도 표시 | 현재 위치 기반 지도 렌더링 (Kakao Maps) | P0 |
| M-02 | 반경 설정 | 슬라이더로 탐색 반경 설정 (500m ~ 5km) | P0 |
| M-03 | 카테고리 필터 | 음식점, 카페, 술집, 활동(방탈출 등) 카테고리별 필터 | P0 |
| M-04 | 장소 카드 | 지도 마커 탭 시 장소 상세 카드 (이름, 평점, 사진, 거리) | P0 |
| M-05 | 장소 선택/확정 | 장소를 선택하여 모임에 연결 | P0 |
| M-06 | 중간 지점 추천 | 참여자들의 위치를 기반으로 중간 지점 자동 계산 | P1 |
| M-07 | 단톡방 공유 | 선택한 장소 정보를 카카오톡 공유 API로 전송 | P1 |
| M-08 | 장소 북마크 | 마음에 드는 장소를 저장 | P2 |

#### 화면 구조

- **상단:** 검색바 + 카테고리 칩(가로 스크롤)
- **중앙:** 지도 영역 (마커 + 반경 원형 오버레이)
- **하단:** 장소 카드 캐러셀 (스와이프)

**목적:** 지난 모임의 추억을 지도와 리스트로 아카이빙

| R-02 | 기록 카드 | 각 모임의 날짜, 장소, 참여자, 대표 사진 표시 | P0 |

| R-06 | 통계 요약 | 상단에 "총 N회 모임, 가장 많이 간 장소, 가장 자주 만난 친구" 표시 | P2 |
| R-07 | 연도/월 필터 | 기간별 기록 필터링 | P2 |

├── id (PK)
├── name

├── id (PK)
├── groupId → Group
├── candidateDates: [Date]

Vote
├── id (PK)
├── sessionId → VoteSession
├── userId → User
├── date

├── id (PK)
├── name
├── address
├── latitude
├── longitude
├── category

## 4. 기술 스택

### 프론트엔드

| 기술 | 선택 이유 |
|------|-----------|
| **Next.js 14 (App Router)** | React 기반 풀스택 프레임워크. SSR/SSG 지원으로 초기 로딩 빠르고, API Routes로 간단한 서버 로직도 처리 가능. Vercel에 원클릭 배포 |
| **TypeScript** | 타입 안전성으로 개발 속도와 안정성 동시 확보 |
| **Tailwind CSS** | 유틸리티 기반으로 앱 수준의 UI를 빠르게 구현. 모바일 반응형에 강함 |
| **shadcn/ui** | 재사용 컴포넌트 라이브러리. 캘린더, 모달, 토스트 등 필수 UI 바로 사용 |
| **Framer Motion** | 화면 전환, 카드 애니메이션 등 네이티브 앱 느낌의 인터랙션 |

### 백엔드 & 인프라

| 기술 | 선택 이유 |
|------|-----------|
| **Supabase** | PostgreSQL 기반 BaaS. 인증, DB, 실시간 구독, 스토리지를 하나로 해결. Firebase보다 SQL 기반이라 관계형 데이터(친구, 모임, 투표)에 적합 |
| **Supabase Auth** | Google, Kakao 소셜 로그인 내장. Row Level Security로 권한 관리 |
| **Supabase Realtime** | 투표 현황, 모임 상태 변경을 실시간 구독 (WebSocket) |
| **Supabase Storage** | 프로필 이미지, 모임 사진 저장 |

### 지도 & 위치

| 기술 | 선택 이유 |
|------|-----------|
| **Kakao Maps SDK** | 국내 장소 데이터 정확도가 Google Maps 대비 압도적. 한국어 POI, 카테고리 검색 지원 |
| **Kakao Local API** | 키워드 장소 검색, 카테고리 검색, 좌표 → 주소 변환 |
| **Kakao Share API** | 카카오톡 단톡방으로 장소/모임 정보 공유 |

### 배포 & DevOps

| 기술 | 선택 이유 |
|------|-----------|
| **Vercel** | Next.js 공식 호스팅. Push만 하면 자동 배포. 커스텀 도메인 무료 |
| **GitHub** | 버전 관리 + Vercel 자동 연동 |

### 선택적 확장 (MVP 이후)

| 기술 | 용도 |
|------|------|
| **PWA (next-pwa)** | 홈 화면 설치, 오프라인 캐시 |
| **FCM (Firebase Cloud Messaging)** | 푸시 알림 |
| **React Native / Expo** | 네이티브 앱 전환 시 |
| **Sentry** | 에러 모니터링 |

## 5. MVP 개발 우선순위 로드맵

### Phase 1 — 뼈대 (1~2주)

- 프로젝트 셋업 (Next.js + Supabase + Tailwind)
- 인증 (회원가입/로그인)
- 하단 탭 네비게이션 + 5개 화면 라우팅
- DB 스키마 생성 및 Supabase 설정

### Phase 2 — 핵심 플로우 (2~3주)

- 홈 캘린더 (월간 뷰 + 일정 등록)
- 친구 검색/추가/목록
- 모임 생성 → 투표 → 확정 전체 플로우
- 모임 상태 실시간 반영

### Phase 3 — 차별화 기능 (1~2주)

- 지도 연동 (Kakao Maps + 장소 검색)
- 반경 설정 + 카테고리 필터
- 장소 선택 → 모임 연결
- 카카오톡 공유

### Phase 4 — 완성도 (1주)

- 기록 히스토리 (타임라인 + 지도 뷰)
- 사진 업로드
- 온보딩 화면
- UI 폴리싱 + 버그 픽스 + 시연 리허설

## 6. MVP 시연 시나리오 (심사위원용)

> **"친구 4명과 이번 주 저녁 모임을 잡는 전체 과정"**

1. 앱 실행 → 홈 캘린더에서 이번 주 일정 확인
2. 친구 탭에서 4명 선택 → "모임 만들기"
3. 모임명 입력, 후보 날짜 3개 설정
4. 참여자들이 투표 (실시간으로 매트릭스 업데이트)
5. 최적 날짜 자동 추천 → 방장이 확정
6. 지도에서 강남역 반경 1km 맛집 검색
7. 장소 선택 → 카카오톡으로 공유
8. 모임 완료 후 → 기록 히스토리에서 추억 확인
