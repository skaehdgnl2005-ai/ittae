# Moim Design System

이 문서는 모임 앱의 디자인 의사결정 기준이다.
모든 화면은 이 문서의 토큰과 원칙을 따르며, 예외 없이 일관성을 유지한다.

---

## 1. 디자인 철학

**"한 사람이 만든 것처럼 보이는 앱"**

토스가 수백 개 화면에서 한 명이 디자인한 듯한 일관성을 유지하는 이유는,
감각이 아니라 **시스템**으로 디자인하기 때문이다.
우리도 같은 원칙을 따른다.

### 핵심 원칙

1. **한 화면, 한 행동.** 사용자가 이 화면에서 할 일은 하나다. 나머지는 숨긴다.
2. **여백이 디자인이다.** 요소를 추가하기 전에 뺄 것을 먼저 찾는다.
3. **텍스트가 UI다.** 아이콘과 색상에 의존하지 않고, 명확한 한국어 문장으로 안내한다.
4. **애니메이션은 의미를 가진다.** 장식적 모션은 없다. 상태 변화를 보여줄 때만 움직인다.

---

## 2. AI 생성 안티패턴 — 절대 하지 않을 것

AI 코딩 도구가 반복적으로 만들어내는 "바이브 코딩" 패턴이 있다.
이 앱은 그 어떤 것도 사용하지 않는다.

### 금지 목록

| 안티패턴 | 왜 문제인가 | 우리의 대안 |
|----------|------------|------------|
| 보라색 → 핑크 그라데이션 배경 | Tailwind indigo 기본값의 산물. 모든 AI 앱이 동일하게 보임 | 단색 배경 + 포인트 컬러는 버튼/배지에만 제한적 사용 |
| Inter, Roboto, system-ui 폰트 | AI가 가장 먼저 선택하는 "안전한" 폰트. 개성 없음 | Pretendard (본문) + Instrument Serif (숫자 강조) |
| 3열 아이콘 그리드 카드 | "기능 소개" 레이아웃의 전형. SaaS 랜딩페이지 느낌 | 풀 와이드 리스트 + 좌측 정렬 텍스트 중심 |
| 히어로 섹션 + 그라데이션 텍스트 | AI가 만드는 랜딩 페이지의 100% 등장 패턴 | 앱이므로 히어로 없음. 콘텐츠가 바로 시작 |
| 반투명 글래스모피즘 카드 | backdrop-filter 남용. 배경 위에 흐릿한 카드 겹침 | 불투명 흰색 카드 + 1px 보더 또는 그림자 |
| 어두운 배경 + 네온 액센트 | "프리미엄 테크" 바이브. 사교 모임 앱과 맞지 않음 | 밝은 배경 기본. 다크모드도 순수한 다크 그레이 |
| 과도한 border-radius (20px+) | 모든 것이 알약 모양. AI 도구의 기본 곡률 | 12px(카드), 8px(버튼/입력), 원형(아바타만) |
| 무의미한 로딩 스피너 애니메이션 | skeleton 없이 빙글빙글 도는 원. 저품질 신호 | 콘텐츠 skeleton + 자연스러운 fade-in |
| 동일 크기 요소의 균등 배치 | 시각적 위계 없음. 모든 것이 같은 중요도로 보임 | 명확한 타이포그래피 위계 (3단계 이상) |
| 보라색 CTA 버튼 (bg-indigo-500) | Tailwind UI 기본 버튼 색상. AI 코드의 가장 강한 지문 | 커스텀 팔레트 기반 Violet 600 단색 버튼 |

### 자가 점검 질문

화면을 완성할 때마다 아래 질문에 답한다.
하나라도 "예"이면 해당 요소를 수정한다.

- "이 화면을 v0이나 Lovable에 프롬프트 한 줄로 넣으면 비슷한 게 나올까?"
- "그라데이션, 글래스모피즘, 네온 효과를 1개라도 사용했나?"
- "Inter 또는 Roboto 폰트를 쓰고 있나?"
- "의미 없이 보라색이 넓은 면적을 차지하고 있나?"

## 3. 컬러 시스템

### 설계 원리

보라색을 메인으로 쓰되, AI 기본 팔레트(Tailwind indigo/violet)와 차별화한다.
OKLCH 색공간에서 직접 설계하여 라이트/다크 모드 간 명도 일관성을 확보한다.

### 컬러 적용 규칙

- 배경은 무조건 Gray 50 (#FAFAFA) 또는 White (#FFFFFF).
- 보라색은 CTA 버튼, 선택 상태, 아이콘, 배지에만 사용한다.
- 텍스트에 보라색을 쓰는 경우는 탭 선택 상태와 링크뿐이다.
- 카드 배경에 보라색을 깔지 않는다. 카드는 항상 흰색이다.
- 다크모드에서 보라색 명도는 라이트모드 대비 1단계 올린다 (600→500).

## 4. 타이포그래피

### 폰트 선택

```
본문/UI:   Pretendard Variable
          (한글 최적화, Apple SD 고딕의 대안, 무료)

숫자 강조: Instrument Serif
          (캘린더 날짜, 통계 숫자 — 에디토리얼 무드)

코드/ID:  JetBrains Mono
          (모임 초대 코드, 디버깅용)
```

**선택 근거:** Pretendard는 한글 가독성과 자간 밸런스가 뛰어나면서도
Inter/Roboto처럼 "AI 기본값"으로 인식되지 않는다.
Instrument Serif는 토스가 숫자에 세리프를 섞어 금융 신뢰감을 주는 것과 같은 역할을 한다.

### 타입 스케일

| 역할 | 사이즈 | 웨이트 | 행간 | 용도 |
|------|--------|--------|------|------|
| Display | 28px | 700 | 36px | 홈 인사말 "오늘의 모임" |
| Title 1 | 22px | 600 | 30px | 화면 타이틀 |
| Title 2 | 18px | 600 | 26px | 섹션 헤딩 |
| Body 1 | 16px | 400 | 24px | 본문 텍스트 |
| Body 2 | 14px | 400 | 20px | 보조 설명 |
| Caption | 12px | 500 | 16px | 배지, 타임스탬프 |
| Number | 32px | Instrument Serif 500 | 40px | 캘린더 날짜, 통계 수치 |

### 규칙

- 한 화면에 Display + Title + Body + Caption 최대 4단계만 사용한다.
- 볼드는 600까지만. 700은 Display 전용.
- 자간(letter-spacing): 한글 0, 영문 -0.01em, 숫자 -0.02em.

## 5. 스페이싱 & 레이아웃

### 기본 그리드

```
화면 폭:      375px 기준 (iPhone SE ~ 14 호환)
좌우 패딩:    20px (고정)
컨텐츠 영역:  335px
컬럼:         단일 컬럼 (모바일 우선이므로 멀티컬럼 사용 안 함)
```

### 스페이싱 스케일 (4px 기반)

```
4px    컴포넌트 내부 미세 간격 (아이콘-텍스트)
8px    관련 요소 사이 (라벨-입력 필드)
12px   카드 내부 패딩
16px   리스트 아이템 사이
20px   섹션 간 구분 (기본)
32px   주요 섹션 간 구분
48px   화면 상단 여백 (타이틀 위)
```

### 규칙

- 여백은 항상 4의 배수. 예외 없음.
- 카드 내부 패딩은 16px (상하좌우 동일).
- 요소 간 간격이 애매하면 항상 더 넓은 쪽을 선택한다.
- 하단 탭바 높이: 83px (safe area 포함), 콘텐츠 영역 위 56px.

## 6. 컴포넌트 규격

### 카드

```css
background: #FFFFFF;
border: 1px solid #E4E4E7;          /* Gray 200 */
border-radius: 12px;
padding: 16px;
box-shadow: 0 1px 2px rgba(0,0,0,0.04);  /* 극히 미세한 그림자 */

/* hover/press 상태 */
background: #FAFAFA;                /* Gray 50 */
transform: scale(0.98);
transition: all 150ms ease;
```

- 카드 안에 카드를 중첩하지 않는다.
- 카드 내부에 보더 대신 Gray 100 배경의 구분선을 사용한다.

### 버튼

```
Primary:    bg Violet 600, text White, h 52px, radius 12px, font 16px/600
Secondary:  bg Gray 100, text Gray 800, h 48px, radius 10px, font 15px/500
Ghost:      bg transparent, text Violet 600, h 44px, 보더 없음
Danger:     bg Red 50, text Red 600, h 48px, radius 10px

비활성 상태: opacity 0.4, pointer-events none
Press 상태:  밝기 -10%, scale(0.97), 150ms ease
```

- 한 화면에 Primary 버튼은 최대 1개.
- 버튼 텍스트는 동사형: "모임 만들기", "투표하기", "장소 선택".

### 아바타

```
Small:   32px (리스트 아이템)
Medium:  44px (모임 상세 참여자)
Large:   64px (프로필 화면)

border-radius: 50%
border: 2px solid White (겹칠 때 구분용)

그룹 아바타: 최대 4개 겹침, 각 -8px margin-left
5인 이상일 때: 4개 + "+N" 배지
```

### 배지/태그

```
투표 중:  bg Warning/10, text Warning, font Caption
확정:     bg Success/10, text Success, font Caption
완료:     bg Gray 100, text Gray 500, font Caption

padding: 4px 8px
border-radius: 6px
```

### 바텀 시트

```
border-radius: 16px 16px 0 0 (상단만)
핸들 바: w 36px, h 4px, bg Gray 300, margin-top 8px
backdrop: rgba(0,0,0,0.3) — 블러 없음 (글래스모피즘 금지)
애니메이션: 아래에서 위로 300ms cubic-bezier(0.32, 0.72, 0, 1)
```

## 7. 아이콘

### 스타일

```
라이브러리: Lucide Icons (라인 스타일, 1.5px stroke)
사이즈:     20px (네비게이션), 24px (액션), 16px (인라인)
컬러:       Gray 500 기본, Violet 600 선택 상태
```

- 아이콘은 단독으로 의미를 전달하지 않는다. 반드시 텍스트와 함께 사용.
- 탭바 아이콘만 예외적으로 텍스트 없이 허용하되, 하단에 10px 라벨 포함.

## 8. 모션 원칙

| 유형 | 속도 | 이징 | 예시 |
|------|------|------|------|
| 마이크로 인터랙션 | 150ms | ease | 버튼 press, 체크박스 토글 |
| 화면 전환 | 300ms | cubic-bezier(0.32, 0.72, 0, 1) | 페이지 이동, 바텀시트 |
| 콘텐츠 등장 | 400ms | ease-out | 리스트 아이템 stagger (각 50ms) |
| 삭제/사라짐 | 200ms | ease-in | 카드 삭제, 토스트 퇴장 |

### 규칙

- 동시에 움직이는 요소는 최대 3개.
- 무한 반복 애니메이션 사용 금지 (로딩 skeleton만 예외).
- 페이지 진입 시 fade + translateY(8px) 조합. 과도한 슬라이드 금지.
- 의미 없는 bounce/elastic 이징 금지.

## 9. 화면별 디자인 노트

### 홈 (캘린더)

- 캘린더 날짜의 숫자는 Instrument Serif로. 에디토리얼 인상의 핵심.
- 오늘 날짜는 Violet 600 원형 배경. 일정 있는 날짜는 하단에 작은 도트(4px).
- 일정 카드는 왼쪽에 3px 두께의 컬러 바 (개인=Gray, 모임=Violet).
- 빈 상태: 일러스트 없이 "아직 일정이 없어요" 텍스트 + CTA 버튼.

### 친구/모임 목록

- 검색바는 Gray 100 배경, 포커스 시 Violet 600 보더.
- 친구 리스트는 아바타(32px) + 이름 + 최근 모임 날짜. 3줄 이하.
- 모임 카드는 모임명 + 상태 배지 + 참여자 아바타 그룹 + 날짜.
- 상태 필터는 상단 칩(가로 스크롤), 선택 칩은 Violet 50 배경 + Violet 600 텍스트.

### 투표 화면

- 날짜 × 참여자 매트릭스는 셀 높이 44px(터치 타겟).
- 투표 상태: ⭕ Violet 500 원, △ Amber 400 삼각, ❌ Gray 300 X.
- 최적 날짜 행은 Violet 50 배경으로 하이라이트.
- 확정 버튼은 화면 하단 고정 (sticky). 전원 투표 완료 전에는 비활성.

### 지도

- 지도가 화면 100%를 차지하고, UI는 그 위에 오버레이.
- 반경 슬라이더는 하단 시트 내부. 지도 위에 반투명 원으로 반경 표시.
- 장소 카드는 하단 시트에서 가로 스와이프 캐러셀.
- 선택된 마커는 Violet 600, 미선택 마커는 Gray 400.

### 기록 히스토리

- 타임라인은 좌측 세로 선(Gray 200) + 각 기록 카드.
- 카드에 사진이 있으면 상단에 둥근 모서리(12px) 썸네일.
- 상단 통계: "총 23회 모임" 숫자는 Instrument Serif Display 사이즈.
- 지도 뷰 전환 시 핀에 방문 횟수 숫자 표시.

## 10. 다크 모드

| 라이트 모드 | 다크 모드 |
|------------|----------|
| 페이지 배경 #FAFAFA | #121212 |
| 카드 배경 #FFFFFF | #1E1E1E |
| 보더 Gray 200 | #2E2E2E |
| 텍스트 Gray 900 | #F4F4F5 |
| 보조 텍스트 Gray 500 | #A1A1AA |
| Violet 600 (CTA) | Violet 500 (한 단계 밝게) |

- 다크 모드에서 순수 검정(#000000) 사용 금지. 최소 #121212.
- 그림자 대신 1px 보더로 카드 구분.
- 보라색 배경 면적은 라이트 모드와 동일하게 유지 (넓히지 않는다).
