Phase 1 실행 전략 선택

TASKS.md 기준 Phase 1은 초기화 + 5개 화면입니다. 어떤 순서로 진행할까요?

현재 상태

구현 파일 없음 · harness + 문서만 존재 · Next.js 프로젝트 생성부터 시작

A

데모 플로우 우선

MVP 핵심 경로를 먼저 완성

진행 순서

  • 0. 초기화 + 공통 기반
  • 1. 홈 (캘린더)
  • 2. 친구/그룹
  • 3. 투표 (가장 중요)
  • 4. 지도
  • 5. 기록

특징

  • TASKS.md 순서 그대로
  • 각 화면 완료 후 /design-check
  • 선형적, 예측 가능
B

컴포넌트 → 화면 병렬

공통 기반 완성 후 화면 병렬 구현

진행 순서

  • 0. 초기화 + 모든 공통 컴포넌트
  • 1~5. 5개 화면을 서브에이전트 병렬

특징

  • 전체 속도 빠름
  • 컴포넌트 재사용성 극대화
  • Phase 0 완료 전까지 화면 없음
C

투표 화면 우선

핵심 차별화 기능 먼저, 나머지는 wrapper

진행 순서

  • 0. 초기화
  • 3. 투표 화면 (가장 먼저)
  • 1. 홈
  • 2. 친구/그룹
  • 4. 지도
  • 5. 기록

특징

  • 심사위원 핵심 데모 포인트 먼저
  • 나머지는 투표를 감싸는 컨텍스트
  • 리스크 조기 해소
