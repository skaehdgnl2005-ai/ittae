인터랙션 설명

날짜 O/X 토글

각 날짜 버튼을 탭하면 미선택 → O → X 순환. O 날짜만 시간표 열이 활성화됨.

양끝 클릭 시간 선택

활성 열에서 시작 슬롯 클릭 → 끝 슬롯 클릭 → 사이 구간 자동 선택 (보라색). 하루에 여러 구간 가능.

구간 해제

이미 선택된 구간의 아무 슬롯을 클릭하면 해당 구간 전체 해제.

결과 히트맵 모드

전원 투표 완료 시 셀 색상이 겹침 인원 수에 따라 농도 변화. 상단 배너에 최적 구간 자동 표시.
